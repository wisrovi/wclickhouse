Introduction

What is wclickhouse?

A lightweight yet powerful ORM specifically optimized for ClickHouse's columnar architecture.

Analytical Power Made Simple

wclickhouse bridges the gap between Python's type safety and ClickHouse's raw analytical speed.

  • Pydantic v2 — Automatic validation of complex analytical types.
  • OLAP Optimized — Native support for Bulk Inserts and DataFrames.
  • Auto-Sync — Zero-effort schema migrations and table creation.

Quick Start Guide

1. Basic Repository & CRUD

from wclickhouse import WClickHouse
from pydantic import BaseModel

class User(BaseModel):
    user_id: int
    username: str

db = WClickHouse(User, db_config)
# Insert single record
db.insert(User(user_id=1, username="wisrovi"))
# Retrieve all
users = db.get_all()

2. High-Performance Bulk Ingest

# Using Pydantic models (fast)
batch = [User(user_id=i, username=f"user_{i}") for i in range(10000)]
db.insert_many(batch)

# Using Pandas DataFrame (ultra fast)
import pandas as pd
df = pd.DataFrame({"user_id": [1, 2], "username": ["a", "b"]})
db.insert_dataframe(df)

3. Advanced Queries

from wclickhouse import QueryBuilder

qb = QueryBuilder("user")
sql, params = qb.select("username").where("user_id > %(min_id)s", min_id=10).build()
results = db.query(sql, params)
